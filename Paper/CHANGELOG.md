- **Ⅴ. 고찰 + Ⅵ. 결론**: 비교 기준을 $n=2$ → **$n=4$**(task_CE 최저=최고 성능)로 변경, 손실을 task_CE 기준으로 서술. 2D-AMoE task_CE 3.394 vs n=4 3.218 → 차이 **0.18**. "평균 ponder 2.12가 최적 n에 근접" 논거는 n=4 기준에서 거짓이 되므로 "모델이 스스로 깊이를 조절" 사실 진술로 대체. 이후 **초록도 동일하게 n=4 / 0.18 기준으로 통일**.

- **Ⅳ-1 서술 수정**: "n=2 최저 → n 증가 시 악화, 깊이 이득 없음"(eval/loss 단정) → **두 지표 구분 설명**으로 교체. eval/loss(LBL 포함)는 LBL이 n에 비례 증가하여 n=2 최저(표1), 순수 task_CE는 n 증가 시 개선되어 n=4 최저(표2). → 초록·고찰·결론(n=4)과 일관.

- **2.3 2D-AMoE**: ponder 손실(KL) 수식 추가 — `_ponder_loss` 코드 기반. 절단·정규화 기하분포 prior $p_G(t)=\lambda_p(1-\lambda_p)^t / Z$, ponder 손실 $\mathcal{L}_{\text{ponder}} = \frac1L\sum_\ell \sum_t p_\ell(t)(\log p_\ell(t)-\log p_G(t))$. 기호 정의 포함.
